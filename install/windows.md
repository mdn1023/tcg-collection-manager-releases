# Install on Windows

**Status: ready.** Takes about a minute; no admin rights needed.

## Install

1. Open the [latest release](../../../releases/latest).
2. Under **Assets**, download
   `TCG-Collection-Manager_<version>_windows-x64-setup.exe`.
3. Run it. Windows will probably show **"Windows protected your PC"**,
   because the installer isn't signed with a paid Microsoft certificate.
   Click **More info → Run anyway**.
4. The app installs for your user only and opens. Sign in.

## Updates

Nothing to do. When a new version is out the app shows **Update now**;
click it and the app restarts on the new version.

## Remove

Settings → Apps → Installed apps → **TCG Collection Manager** → Uninstall.
